Mes réalisations

FlowPilot est une application web conçue pour aider les startups et petites entreprises à gérer leurs prospects, clients, ventes et tâches dans une seule plateforme. Le projet met en œuvre une architecture moderne basée sur Django REST, React et une API sécurisée avec gestion des rôles afin d’offrir une solution performante et évolutive.

Cashlog est une application moderne et intuitive permettant de suivre, organiser et analyser ses dépenses quotidiennes. Pensée pour les utilisateurs qui veulent garder le contrôle sur leur budget sans complexité, elle offre une interface simple, rapide et efficace.

TaskMind est une application moderne de gestion de tâches qui intègre un assistant IA pour aider les utilisateurs à prioriser leurs activités, organiser leur journée et devenir plus productifs.
